## How to use

Each file holds the `Solution` class as submitted on GeeksforGeeks. To run one locally, add a `main()` with the needed headers (`#include <bits/stdc++.h>` and `using namespace std;`) and compile:

```bash
g++ -std=c++17 "path/to/solution.cpp" -o solution && ./solution
```
